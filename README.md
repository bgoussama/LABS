## 🎯 Objectif du lab

Ce projet Android permet de :
- Consommer un Web Service PHP 8
- Envoyer des requêtes HTTP avec Volley
- Récupérer des données au format JSON
- Afficher les données dans une application Android

---

## 🧰 Technologies utilisées

- Java (Android)
- Android Studio
- Volley (HTTP requests)
- PHP 8 (Backend)
- JSON

---

## 🚀 Fonctionnalités

- Connexion à une API REST PHP
- Envoi de requêtes HTTP
- Récupération de données JSON
- Affichage dans l’interface Android
